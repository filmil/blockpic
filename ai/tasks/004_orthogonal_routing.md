# Task: Orthogonal Wire Routing (Phase 2)

## Objective
Implement automatic orthogonal routing for wires and buses.

## Requirements
- Implement 90-degree bend logic for connections.
- Support `L-shape` and `Z-shape` routing hints.
- Implement bus rendering: thickness variations and crossline indicators.
- Minimize wire crossings where possible.

## Deliverables
- `router` package or enhanced `renderer` logic.
- Visual validation suite for various routing scenarios.
