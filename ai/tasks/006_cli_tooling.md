# Task: CLI Tooling (Phase 3)

## Objective
Develop a command-line tool for the Hodos ecosystem.

## Requirements
- Commands: `hodos compile <file>`, `hodos render <file> --format [png|svg|pdf]`.
- Support for watching files and re-rendering on change.
- Integration with the documentation pipeline.

## Deliverables
- `main` package and compiled binary.
- Documentation for CLI usage.
