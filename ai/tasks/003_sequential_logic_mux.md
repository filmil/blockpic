# Task: Sequential Logic and MUX (Phase 2)

## Objective
Expand the shape library to include sequential elements and multiplexers.

## Requirements
- Implement `FLIPFLOP` (D, JK, T, SR) shapes.
- Implement `MUX` and `DEMUX` trapezoidal shapes.
- Support internal labels and specialized pins (e.g., clock triangle, bubble for inversion).

## Deliverables
- Expanded block library.
- Documentation for sequential block parameters.
