# Task: XOR and Dynamic Gate Sizing (Phase 2)

## Objective
Implement the XOR gate shape and add support for dynamic gate sizing based on the number of inputs/outputs.

## Requirements
- Implement the IEEE `XOR` gate shape (double curved input).
- Calculate default block height based on the number of pins if `size` is not specified.
- Ensure pins are evenly distributed along the calculated boundary.

## Deliverables
- Updated `shapes` and `renderer` packages.
- Visual test cases with multi-input gates.
