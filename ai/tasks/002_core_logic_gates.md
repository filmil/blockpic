# Task: Core Logic Gates (Phase 1)

## Objective
Implement specialized rendering and logic for basic gates: AND, OR, NOT.

## Requirements
- Define standard shapes for `AND`, `OR`, `NOT` gates based on IEEE standards.
- Support parameter mapping for these gates (e.g., number of inputs).
- Ensure port alignment follows the "left-to-right" flow by default.

## Deliverables
- Predefined block library for basic gates.
- Sample diagrams demonstrating gate rendering.
