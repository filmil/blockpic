# Task: Automatic Grid Layout (Phase 2)

## Objective
Implement a basic automatic layout algorithm to position blocks if no manual layout is provided.

## Requirements
- Implement a simple grid or flow-based layout engine.
- Respect container boundaries.
- Align blocks to a configurable grid (e.g., 10px or 20px).

## Deliverables
- `layout` package.
- CLI flag `--auto-layout` to trigger the engine.
