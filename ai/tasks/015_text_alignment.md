# Task: Text and Label Alignment (Phase 2)

## Objective
Improve the placement and alignment of text labels for blocks and pins.

## Requirements
- Centered labels for internal block text (e.g., "REGISTER").
- Improved spacing for pin labels to avoid overlap with wires.
- Support for multi-line block parameters in the diagram.

## Deliverables
- Updated `renderer` package.
- Visual test cases with long labels and multi-line text.
